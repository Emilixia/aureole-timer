# Chronomark Assets

Place your custom GIF files here to use them as default assets in the app.

| File | Purpose |
|------|---------|
| `startup-logo.gif` | Animated logo shown on the startup splash screen |
| `thumbsup.gif` | Image shown in notification toast popups |

**To add a file:** drop your .gif (or any image) with the exact filename above into this folder, then rebuild the app (`npm run build`).

**Alternatively**, you can upload these files at any time through the app's Settings panel without rebuilding:
- **Startup Logo**: Settings → Appearance → "Upload Startup Logo"
- **Thumbs-Up**: Settings → Notifications → "Upload Thumbs-Up"
